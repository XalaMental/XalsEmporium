# Xal's Emporium

A housing-decor collection tracker for World of Warcraft - finds every decor
item you're missing and tells you where to get it.

## Features

Features land here as they're built. This is the initial scaffolding
release - no housing-decor features exist yet.

## Commands

| Command | What it does |
|---|---|
| `/xemp` | Show the help list |
| `/xemp options` | Open the settings window |

## Installing

Install from CurseForge, or drop the `XalsEmporium` folder into
`World of Warcraft\_retail_\Interface\AddOns\`.
